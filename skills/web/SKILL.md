# 联网搜索技能（web）

大白的基础能力：像编程助手一样能查实时信息，而不是凭空编造。

## 工具

| 工具 | 用途 |
|------|------|
| web_search(query, max_results?) | 按关键词搜索网页，返回 标题/链接/摘要（默认 5 条，最多 10 条） |
| read_web(url, mode?, keyword?, js?, max_chars?) | 深挖网页：text 正文（含表格）/ links 链接清单 / headings 标题大纲 / tables 表格 / html 原始结构；复杂或 JS 渲染页面自动用无头 Chrome 导出真实 DOM；keyword 站内定位关键词上下文 |

## 规则

1. 需要实时信息、新闻、文档、教程、资料、查证时，**先搜再答**，不要编造；
2. 搜索没结果就如实说“没查到”，不要硬编；
3. 搜索结果里的链接用 read_web 打开看详情，不要凭标题猜内容；
4. **深挖套路**：先 mode=text 读正文 → 内容不够就 mode=headings 看结构 → 顺着 mode=links
   往下挖二级链接 → 数据类页面用 mode=tables；JS 渲染页面（正文太少）会自动用无头 Chrome，
   也可以显式 js=true；
5. 直连失败会自动走本地代理 127.0.0.1:7890 重试，被墙也能搜；
6. 只读操作，不会修改任何文件。
